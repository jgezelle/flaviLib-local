### Merge with the original Class 1b seed alignment

`esl-alimerge` requires `#=GC RF` on every input alignment to know the match-column
mapping. The original CL_Class_1b_xrRNA_final.sto was built with `cmbuild` using
`RF no` (confirmed from the .cm header), so it has no RF line — but the CM itself
still has a match-column definition. Re-derive RF for the original seed by
realigning it to its own CM, rather than hand-editing an RF line in:

```bash
# extract the original class 1b seed sequences as raw fasta
esl-reformat fasta ../stockholm/CL_Class_1b_xrRNA_final.sto \
  > cm_compare/class1b_seed_raw.fasta
grep -c "^>" cm_compare/class1b_seed_raw.fasta   # expect 88

# realign to its own CM — this produces an RF-annotated Stockholm
cmalign --cpu 4 --outformat Stockholm \
  -o cm_compare/class1b_seed_with_RF.stk \
  ../cm/CL_Class_1b_xrRNA_final.cm cm_compare/class1b_seed_raw.fasta

grep "^#=GC RF" cm_compare/class1b_seed_with_RF.stk   # confirm it's present now
```
#### Now, both inputs to `esl-alimerge` carry RF from the same CM's match-column definition, so the merge is guaranteed column-consistent:

```bash
esl-alimerge --rna -o cm_compare/class1b_merged.stk \
  cm_compare/class1b_seed_with_RF.stk \
  cm_compare/hits_confident_vs_class1b.stk

grep -v "^#" cm_compare/class1b_merged.stk | grep -v "^//" | grep -v "^$" | \
  awk '{print $1}' | sort -u | wc -l
# expect 110
```

### Split by genus: mlocarna independently, don't force a combined alignment

The pooled 59-sequence mlocarna alignment produced only two small, weakly-
supported stem-loops (energy -3.25, covariance -0.79) spanning a small
fraction of the alignment -- not consistent with one shared structural family
across Hepaci/Pegi/Pesti. Split and align each genus separately.

```bash
mkdir -p candidate_short1b/by_genus

# hepaci confident set (already have this from cm_compare/hits_confident_v2.fasta)
cp cm_compare/hits_confident_v2.fasta candidate_short1b/by_genus/hepaci.fasta

cp candidate_short1b/pesti_unclass_novel_dedup.fasta candidate_short1b/by_genus/pesti.fasta

for genus in hepaci pegi pesti; do
  mlocarna candidate_short1b/by_genus/${genus}.fasta \
    --stockholm --consensus-structure=alifold \
    --tgtdir candidate_short1b/by_genus/${genus}_mlocarna
done
```

For each, check the alifold consensus line at the end of the run before going
any further -- look for a stronger, more complete structure than the pooled
attempt gave (more base pairs, better covariance-supported energy, spanning
more of the alignment). If a genus-specific run still looks weak/fragmented,
that genus itself may need splitting further (e.g. by sub-genus or by the
tandem-paralog pattern seen with hepaci earlier) rather than assuming genus
boundaries alone will fix it.

Note the hepaci confident set already showed a real, consistent partial match
to class1b (cm 2-61/74, PP 0.7-0.9) -- so hepaci's own mlocarna run is the
one most likely to produce a clean, well-supported structure. Pegi and pesti
are less proven at this point; their mlocarna results are the real test of
whether they're independently well-structured RNAs or not.
